# FruitRabbit Keycap Lab

FruitRabbit 키캡을 브라우저에서 직접 꾸미고 확인할 수 있는 인터랙티브 웹 프로젝트입니다.

## 주요 기능

- 키캡 디자인 실시간 미리보기
- 다양한 스타일과 옵션 적용
- 한국어 및 영어 지원
- 별도의 설치 없이 브라우저에서 실행

## 사용 기술

- HTML
- CSS
- JavaScript
- Three.js

## 데모

https://crzone.github.io/ver/

## 실행 방법

저장소를 내려받은 후 `index.html`을 브라우저에서 열어 실행할 수 있습니다.

## 라이선스

프로젝트의 코드와 이미지 사용 조건은 추후 추가될 예정입니다.
