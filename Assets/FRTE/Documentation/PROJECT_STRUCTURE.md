# Project Structure Directory Layout

The workspace is organized into isolated, ASMDEF-bounded folders:
- `Assets/FRTE/Core/`: Base types, registries, event system, and project session models.
- `Assets/FRTE/Photo/`: Camera/gallery bridges and input transformers.
- `Assets/FRTE/Physics/`: 2D Spring-damper vertex solvers and debug overlays.
- `Assets/FRTE/Materials/`: Presets definitions and UI selection.
- `Assets/FRTE/Decoration/`: Placed accessories, handles, and landmark alignment adapters.
- `Assets/FRTE/PhotoZone/`: Backdrops, characters, and foreground layering.
- `Assets/FRTE/Surprise/`: Cooldown managers and pooled effect generators.
- `Assets/FRTE/Collection/`: Storage repository for discoveries.
- `Assets/FRTE/Export/`: PNG captures, MP4 recorders, and native platform Share adapters.
