# Running inside Unity Editor

### Instructions
1. Open the scene `Assets/FRTE/Samples/Scenes/FRTE_MaterialPresetDemo.unity`.
2. Ensure you have the `Game` tab visible.
3. Click the **Play** button.
4. Use the left mouse button to simulate single touch inputs (move, press, bounce).
5. Open the **Debug Panel** on the left screen margin to monitor FPS, real-time vertex displacement, and swap presets.
