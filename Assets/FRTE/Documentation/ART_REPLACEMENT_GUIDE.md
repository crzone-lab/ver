# Art Replacement Guide

To customize visual elements without modifying source code:
- **Decoration Accessories**: Save transparent PNG files (512x512) into [Decoration/Art/](file:///Users/crzone/.gemini/antigravity/scratch/fruit-rabbit-touch-engine/Assets/FRTE/Decoration/Art/). Update the corresponding `DecorationPreset` ScriptableObject references.
- **PhotoZone Backgrounds**: Save background layouts (1080x1920) under [PhotoZone/Art/](file:///Users/crzone/.gemini/antigravity/scratch/fruit-rabbit-touch-engine/Assets/FRTE/PhotoZone/Art/). Update `PhotoZonePreset` sprite assignments.
- **Surprise Event Sprites**: Save surprise shapes (e.g. popups) into [Surprise/Art/](file:///Users/crzone/.gemini/antigravity/scratch/fruit-rabbit-touch-engine/Assets/FRTE/Surprise/Art/).
