# FruitRabbit Squishy Touch Engine (FRTE) SDK v1.0

This SDK provides a high-performance, GC-optimized local 2D mesh deformation framework and gameplay composition layers for Unity mobile projects (iOS/Android).

### Features
- **Photo Engine**: Local GPU texture scaling, crops, and rotation.
- **Squishy Physics**: Mass-spring-damper solvers, wobbles, and local constraints.
- **Material Presets**: 12 fruit and generic bouncy material configurations.
- **Decoration System**: Automated face landmark placement (hats, ears, glasses) and 30 placeholder accessories.
- **PhotoZone**: 10-layer rendering backdrop compositions.
- **Surprise Events**: 9 tap and duration triggered particle/peek animations.
- **Collection Book**: Auto-discovery tracker with PlayerPrefs JSON storage.
- **Export Engine**: Local PNG captures (with transparent alpha support), MP4 recorder mocks, and native Share Sheets.

### Quick Start
1. Open the Unity project.
2. Locate the Demo scene: [FRTE_MaterialPresetDemo](file:///Users/crzone/.gemini/antigravity/scratch/fruit-rabbit-touch-engine/Assets/FRTE/Samples/Scenes/FRTE_MaterialPresetDemo.unity).
