# Project Setup Guide

### Requirements
- **Unity Version**: 2022.3 LTS (or later stable releases).
- **Platform Modules**: iOS Build Support, Android Build Support.
- **Packages**:
  - `com.unity.inputsystem` (Input System package)
  - `com.unity.test-framework` (Test Runner)

### Installation
1. Open the project folder in Unity Hub.
2. Select Unity 2022.3.x LTS.
3. Allow packages to resolve.
4. Set active build platform to Android or iOS in `Build Settings`.
