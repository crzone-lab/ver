# FruitRabbit Decoration Art Guide

This folder contains localized directories for replacement accessories:
- `FruitRabbitEars/`
- `FruitHats/`
- `Glasses/`
- `FaceStickers/`
- `HandProps/`
- `Frames/`
- `SpeechBubbles/`

### Import Settings Guidance:
- **Texture Type**: Sprite (2D and UI)
- **Sprite Mode**: Single
- **Pivot**: 
  - Ears / Hats: Bottom-Center or Center
  - Glasses: Center
  - Stickers / Props: Center
- **Resolution**: 256x256 or 512x512 pixels recommended
- **Format**: 32-bit Transparent PNG
- **Pixels Per Unit**: 100
