# FruitRabbit Surprise Art Guide

This folder contains localized directories for particle/peek animations:
- `FruitParticles/`
- `FruitRabbitPeek/`
- `Hearts/`
- `Stars/`
- `Ripples/`
- `SpeechBubbles/`

### Effect Sprite Requirements:
- **Format**: transparent PNG
- **Pivot**: Center
- **Resolution**: 128x128 pixels recommended for particles, 256x512 for character Peeks.
