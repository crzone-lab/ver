# FruitRabbit PhotoZone Art Guide

This folder contains localized directories for background layouts:
- `StrawberryFarm/`
- `LemonGarden/`
- `PeachVillage/`
- `WatermelonBeach/`
- `GrapeTunnel/`

### Layer Asset Settings:
- **Background / Midground / Foreground / Frame / LightingOverlay**:
  - **Texture Type**: Sprite (2D and UI)
  - **Resolution**: 1080x1920 (Portrait aspect ratio matching full screen)
  - **Format**: 32-bit PNG (with transparency for midground/foreground overlays)
  - **Pivot**: Center (0.5, 0.5)
